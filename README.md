# 🚗 CertiRide – Mobile Applications

CertiRide is a secure and transparent blockchain-powered platform designed to store and verify all vehicle-related records — service history, accident logs, ownership transfers, diagnostics, and more.  
Both mobile apps work together to ensure trust between **vehicle owners** and **mechanics**.

---

# 📲 Vehicle Owner App

The Vehicle Owner App allows owners to access verified vehicle records stored on Hyperledger Fabric.  
Owners can view service history, accident records, ownership changes, warranty information, and securely upload documents.

# 🔧 Mechanic App

The Mechanic App enables authorized workshops to create verified service records, attach invoices, update maintenance logs, and push authenticated data to the blockchain.

# 🌐 About CertiRide

CertiRide ensures tamper-proof vehicle lifecycle data through blockchain technology, enabling:  
- Trusted service history  
- Secure document uploads  
- Transparent ownership management  
- Verification for buyers and sellers  

Designed for Sri Lanka’s automotive ecosystem with future expansion in mind.
